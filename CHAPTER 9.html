9.1 Introduction

What is C++, and where did it come from?

Straight from the textbook, with a few extra explanations to help the ideas stick.

Textbook Definition

C++ is one of the most popular programming languages which supports both procedural and Object Oriented Programming paradigms. Because of this, C++ is called a hybrid language. C++ is a superset (extension) of its predecessor, the C language. Bjarne Stroustrup named his new language "C with Classes". The name C++ was coined by Rick Mascitti, where ++ is the C language increment operator.

Easy Explanation: "Hybrid" means "mixed". C++ mixes two styles of programming — step-by-step instructions (procedural, like C) and organising code into objects (Object Oriented Programming). It's like a vehicle that can run on two kinds of fuel.

Bjarne Stroustrup — Inventor of C++

Bjarne is a Danish Computer Scientist born on 30th December 1950. He has a Master's degree in Mathematics and Computer Science (1975, Aarhus University, Denmark) and a Ph.D. in Computer Science (1979, University of Cambridge, England).

History of C++ timeline

1979

Bjarne Stroustrup develops C++ at AT&T Bell Laboratory. C++ is derived from C, and influenced by Simula, BCPL, Ada, ML, CLU and ALGOL 68.

Till 1983

The language is called "New C" and "C with Classes".

1983

Rick Mascitti renames it C++.

Benefits of learning C++

  • C++ is a highly portable language and is often the language of choice for multi-device, multi-platform app development.
  • C++ is an object-oriented programming language and includes classes, inheritance, polymorphism, data abstraction and encapsulation.
  • C++ has a rich function library.
  • C++ allows exception handling, inheritance and function overloading — which are not possible in C.
  • C++ is a powerful, efficient and fast language, used from GUI applications to 3D graphics for games to real-time mathematical simulations.
Exam point: "C is superset extended into C++" and "C++ was called C with Classes before 1983" are common one-mark facts.

Every program is built from five kinds of pieces

A token is the smallest individual unit in a program.

C++ program statements are constructed by many different small elements such as commands, variables, constants, and many more symbols called operators and punctuators. These individual elements are collectively called Lexical units or Lexical elements or Tokens.

9.3.1 Keywords

Words the compiler has already claimed

Textbook Definition

Keywords are the reserved words which convey specific meaning to the C++ compiler. They are the essential elements to construct C++ programs. Most of the keywords are common to C, C++ and Java. C++ is a case sensitive programming language, so all keywords must be in lowercase.

Identifiers containing a double underscore (__) are reserved for use by C++ implementations and standard libraries, and should be avoided by users.

9.3.2 Identifiers

Names you choose for your program's parts

Textbook Definition

Identifiers are the user-defined names given to different parts of a C++ program, viz. variables, functions, arrays, classes, etc. These are the fundamental building blocks of a program.

Rules for naming an identifier

  • The first character of an identifier must be an alphabet or an underscore (_).
  • Only alphabets, digits and underscore are permitted. Other special characters are not allowed.
  • C++ is case sensitive — it treats upper and lower-case characters differently.
  • Reserved words (keywords) cannot be used as an identifier name.
  • As per ANSI standards, C++ places no limit on identifier length, so all characters are significant.
You may use an underscore to separate parts of a name (e.g. total_sales is valid, but total sales with a space is invalid). You may also use "capital style" / camelCase, e.g. tamilMark.

    (1) Integer Constants — Decimal, Octal, Hexadecimal Textbook

    TypeRuleValidInvalid & reason

    The suffix L/l or U/u added to any constant forces it to be treated as a long or unsigned constant respectively.

    (2) Real (Floating Point) Constants Textbook

    A real constant has a fractional component. It can be written in fractional form (must have at least one digit before and after the decimal point) or exponent form (Mantissa + E/e + Exponent).

    Exponent formMeaningFractional value
    5.864 E110¹ × 5.86458.64

    Example: 58000000.00 may be written as 0.58 × 10⁸ or 0.58E8.

    Character & String Literals, Boolean literals Textbook

    • Boolean literals represent true or false. Internally true = 1 and false = 0.
    • Character constant: any valid single character enclosed in single quotes, e.g. 'A', '2', '$'. "A" (double quotes) is invalid as a character constant. Every character has an ASCII value — 'A' is 65.
    • String literal: a sequence of characters in double quotes, e.g. "Welcome". A null character '\0' is automatically added at the end, so "welcome" is really stored as "welcome\0" — 8 characters, not 7.

    9.3.4 Operators

    Symbols that act on data

    Textbook Definition

    The symbols which are used to perform mathematical or logical operations are called Operators. The data items or values that the operators act upon are called Operands.

    operand5 + operand6 "+" is the operator; 5 and 6 are the operands

    C++ classifies operators by the number of operands they need:

    • Unary Operators — require only one operand
    • Binary Operators — require two operands
    • Ternary Operators — require three operands

    C++ Binary Operators are further classified as: (1) Arithmetic (2) Relational (3) Logical (4) Assignment (5) Conditional.

    Increment & Decrement Operators (Unary)

    ++ (increment) adds 1 to its operand; -- (decrement) subtracts 1. x++ or ++x is the same as x = x + 1;. They can appear as prefix (before the variable) or postfix (after the variable); with the prefix form, C++ performs the increment/decrement before using the operand.

    (2) Relational Operators Textbook

    Relational operators determine the relationship between operands. The result is always a Boolean value: 1 for True, 0 for False. All six are binary operators.

    OperatorOperationExample
    >Greater thana > b
    <Less thana < b
    >=Greater than or equal toa >= b
    <=Less than or equal toa <= b
    ==Equal toa == b
    !=Not equala != b

    (3) Logical Operators Textbook

    OperatorOperationDescription
    &&ANDCombines two relational expressions. Returns 1 (True) only if both are true, otherwise 0 (False).
    ||ORCombines two relational expressions. Returns 1 (True) if either is true; returns 0 only if both are false.
    !NOTWorks on a single expression — negates the truth value. (Unary; AND/OR are binary.)

    Must Know

    • C++ is a hybrid language — supports both procedural and OOP paradigms.
    • C++ was developed by Bjarne Stroustrup at AT&T Bell Laboratory in 1979; named C++ by Rick Mascitti in 1983.
    • A Token is the smallest individual unit in a program: Keywords, Identifiers, Literals, Operators, Punctuators.

    • Relational/Logical expressions evaluate to 1 (true) or 0 (false).

    One-Minute Revision

    C++ = hybrid (procedural + OOP), by Stroustrup (1979), named by Mascitti (1983). A program is built from Tokens: Keywords (fixed, lowercase), Identifiers (your names, start with letter/underscore, no keywords), Literals (Decimal/Octal/Hex/Real/Character/String/Boolean — fixed values), Operators (Arithmetic, Relational, Logical, Assignment, Conditional — Unary/Binary/Ternary), and Punctuators ( { } ( ) [ ] , . -> :: ). Everything obeys a fixed Precedence order, highest to lowest: () [] → ++/-- → * / % → + - → relational → == != → && → || → ?: → = → shorthand → ,.
