Data Types, Variables and Expressions

தரவு வகைகள், மாறிகள் மற்றும் கோவைகள்

Every C++ program works with data. Before the computer can store or process any piece of data, it needs to know exactly what kind of data it is dealing with. This chapter builds that foundation — data types, variables, formatted output, expressions and type conversion.

Textbook Why data types matter

Every programming language has two fundamental elements: data types and variables. C++ provides a predefined set of data types for handling data items — these are called fundamental or built-in data types. A programmer can also create user-defined data types.

SECTION 9.12

C++ Data Types

In C++, data types are classified into three main categories. This chapter focuses only on the fundamental (built-in) types.

TextbookThree categories
  • Fundamental data types — int, char, float, double, void
  • User-defined data types — structure, union, class, enumeration
  • Derived data types — array, function, pointer, reference
Easy explanationThink of it like sorting containers

A data type tells the computer what kind of container to use in memory — a small box for a whole number, a slightly bigger one for a character, and a wider box for numbers with decimals.

The five fundamental data types

TypeWhat it storesTextbook note
intWhole (integer) numbers onlyIf you store a fractional value, only the integer part is kept — the fraction is ignored.
charA single valid ASCII characterOften called an integer type too, since characters are stored as their ASCII code.
floatFloating point (decimal) valuesCan represent values between integers and a much greater range — but is slower than int.
doubleDouble-precision floating pointOccupies double the space of float — more fractional digits, larger and slower than float.
voidAn empty set of valuesUsed as a return type for functions that return nothing.

SECTION 9.13

Variables

Variables are user-defined names assigned to specific memory locations in which values are stored. Because they are named locations, they are also called symbolic variables.

Textbook definitionR-value and L-value
  • R-value — the data stored in a memory location
  • L-value — the memory address in which the R-value is stored

Syntax

<data type> <variable name>;
// example
int num1;
// multiple variables of the same type
int num1, num2, sum;

Simulation: declare variables & watch memory

The textbook's Figure 9.15 shows int num1, num2, sum; allocating one memory box per variable. Declare a variable below and see what happens before it is given a value.

Variable declaration simulator
Declare a variable to see it get memory space with a random junk / garbage value — because no value was assigned yet.
IllustrationProgram with junk values
int num1, num2, sum;
cout << num1 << endl;
cout << num2 << endl;
cout << num1 + num2;

Because num1 and num2 are never given a value, they hold unknown "Junk" or "Garbage" values, and their sum is unpredictable.

Exam point

Always initialize a variable before using it in an expression — otherwise the result is unpredictable garbage, not zero.

Common mistake: assuming an uninitialized variable automatically starts at 0. In C++ it does not — it holds whatever was already in that memory location.

SECTION 9.13.4 – 9.13.5

The const Access Modifier & References

const

const is the keyword used to declare a constant. It modifies / restricts the accessibility of a variable, so it is known as an Access modifier. Once declared const, a variable's value can never be changed during execution.

const violation simulator
const int num = 100;
cout << num;
num = num + 1;   // try to change it
Click "Run this program" to see what the compiler does.
Exam point: Turbo compiler reports "Cannot modify the const object"; Dev C++ reports "assignment of read only memory num".

References

A reference provides an alias (another name) for a previously defined variable. It is declared using a base type and an & symbol.

<type> <& reference_variable> = <original_variable>;
Reference / alias simulator
int num;
int &temp = num;   // temp is now an alias for num
num = 100;

temp shares num's memory address — changing num also changes what temp shows, because they are the same memory location.
SECTION 9.14

Formatting Output

Manipulators are functions designed to work with << and >> to format output for easy reading. Commonly used ones: endl, setw, setfill, setprecision, setf.

endl is a member of the iostream header. setw, setfill, setprecision, setf are members of the iomanip header.

endl vs '\n'

ManipulatorWhat it does
endlInserts a new line and flushes the buffer (flush = clean the buffer)
'\n'Inserts only a new line

setw() — field width

setw(number) sets the minimum number of characters for the next output field. Values are shown right-aligned within that field width.

setw() playground
cout<<setw(25)<<"Basic Pay : "<<setw(10)<<basic<<endl;
Field 1 reserves the given width for the label text, field 2 reserves width for the value — both right-aligned, padded with spaces on the left.

Illustration 9.10 — Net salary program

Basic Pay : 12000 Dearness Allowance : 1250 House Rent Allowance : 1450 Gross Pay : 14700 G.P.F : 1325 Income Tax : 1470 Net Pay : 11905

setprecision() — controlling digits

Displays numbers with fractions in a specific number of digits, counted left to right (unless fixed or scientific is set, in which case it counts decimal places only).

setprecision() playground
float hra = 1200.123;
cout << setprecision(5) << hra;
"default" mode counts total significant digits left-to-right. "fixed" mode fixes the number of digits after the decimal point.
Exam examples from text: default setprecision(5) on 1200.123 → 1200.1. With ios::fixed, setprecision(2) on 0.1 → 0.10. With ios::scientific, setprecision(2) on 0.1 → 1.00e-001.
SECTION 9.15

Expressions

An expression is a combination of operators, constants and variables arranged as per the rules of C++. It may consist of one or more operands and zero or more operators, and may include function calls that return values. There are seven types of expressions in C++.

SECTION 9.16

Type Conversion

Converting one fundamental data type into another is called Type Conversion. C++ provides two kinds: implicit and explicit.

Implicit (automatic) type conversion

Performed by the compiler automatically, whenever different data types are mixed in one expression. The rule: the "smaller" type is converted to the "wider" type — this is called Type Promotion.

int a=6;
float b=3.14;
cout << a+b;
9.14

a (int) is converted to float because float is wider than int.

PRACTICE

Debugging Lab

Each program below has one mistake based on a concept from this chapter. Try to spot it before revealing the fix.

Debug #1 Logical error — uninitialized variables
❌ CODE
int num1, num2, sum;
sum = num1 + num2;
cout << sum;
✅ WHAT'S WRONG

num1 and num2 were declared but never given values — they hold garbage. Fix: read them with cin or assign values before adding.

Debug #2 Runtime/compile error — modifying a constant
❌ CODE
const int num=100;
num = num + 1;
cout << num;
✅ WHAT'S WRONG

num is declared const, so its value can never change after initialization. The compiler rejects num = num + 1;. Fix: remove const, or use a normal (non-const) variable if the value needs to change.

Debug #3 Data type mismatch
❌ CODE
long float x;
✅ WHAT'S WRONG

long is a valid modifier for integer types, but there is no such combination as "long float" in C++ — the modifier for extra floating-point precision is long double, not long float.

Exam Preparation

Points to Remember Textbook summary

  • Every programming language has two fundamental elements: data types and variables.
  • C++ data types fall into three categories: (1) Built-in data types (2) User-defined data types (3) Derived data types.
  • Variables are named spaces to hold values of a certain data type.
  • There are five fundamental data types in C++: char, int, float, double and void.
  • The C++ compiler allocates specific memory space for each data item according to the compiler's standards.
  • Variables are user-defined names assigned to a memory location in which values are stored.
  • Declaration instructs the compiler to allocate memory as per the type specified with the variable name.
  • Manipulators format output; they work with the insertion (<<) and extraction (>>) operators.
  • An expression is a combination of operators, constants and variables arranged per the rules of C++.
  • Type Conversion means converting one fundamental data type into another — implicit or explicit.

Must Know

5 fundamental types: char, int, float, double, void — with their exact byte sizes (1, 2, 4, 8 bytes).

4 modifiers: signed, unsigned, long, short — usable on any fundamental type except void.

R-value vs L-value: R-value is the data; L-value is the memory address.

const locks a variable's value permanently after initialization.

endl flushes the buffer; '\n' does not.

7 expression types: Constant, Integer, Float, Relational, Logical, Bitwise, Pointer.
